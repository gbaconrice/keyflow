### 止まっている理由

このクラウド環境にGitHubアカウントが接続されていないため、リポジトリの作成・push・GitHub Actions（macOS）でのビルドができていない。
接続後にやること:
1. 新規リポジトリ（例: `keyflow`）を作成し、`main` をpush
2. GitHub Actions の `Build` の結果を確認し、iOS SDKでのコンパイルエラーを直す
3. 成果物 `KeyFlow-ipa` と `screenshots` を確認
4. docs/INSTALL.md の手順で実機に入れ、下の「実機確認項目」を順に確かめる

## 未完了・今後の改善

### 実機確認のあとに判断するもの
- 外部変更の検出（0.5秒の判定時間）の調整
- 振動がフルアクセスなしで動くか
- 既定の高さ・フリック判定距離の微調整（実際の指で決める）
- メモリ使用量（Instrumentsが使えないので、長時間使用で落ちないかで判断）

### 未実装
- 英字の12キー（フリック）配列。いまはQWERTYのみ
- 記号・顔文字の一覧画面
- 選択したテキストの再変換（`selectedText`の読みを推定して候補を出す）
- ローマ字入力（QWERTYで日本語）
- 候補の長押しで学習を忘れさせる操作
- 英語の予測変換
- キーボード内の簡易クリップボード（フルアクセス不要の範囲）
- Zenzai（ニューラル変換）の採否評価。精度は上がるがメモリが増える

### 既知の問題
- 上流（AzooKeyKanaKanjiConverter main）に予測時のデバッグ出力（`print`）が残っている
- アプリ内プレビューは辞書を持たないため、変換候補はひらがな・カタカナだけ
